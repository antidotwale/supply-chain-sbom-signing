# supply-chain-sbom-signing

Generate an SBOM, sign container images and verify the signature before deploy.

> Personal lab project. Built in my own AWS, Azure and GitHub accounts for learning and practice. It is not work I did for any employer or client. Any secrets, keys or tokens shown in test data are fake.

## What this builds

An SBOM created in CI, an image signed in the pipeline, and a verify step that refuses to deploy an unsigned image.
